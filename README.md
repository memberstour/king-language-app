# 킹링고 (KingLingo)

매일 5분, 초등 수준 **영어 · 중국어** 문장을 듣고 따라 말하며 익히는 모바일 우선 학습 PWA입니다.
Duolingo의 게임 같은 흐름과 Speak의 말하기 연습을 참고했고, **빌드 과정 없이** 정적 파일만으로 동작합니다.

- 앱: <https://memberstour.github.io/king-language-app/>
- 구성: `index.html` + `css/styles.css` + `js/*.js` (프레임워크·외부 CDN 없음)

## 기능

| 탭 | 내용 |
| --- | --- |
| 오늘 | 오늘의 목표(30 XP) 링, 스트릭, 14일 코스, 하루 4개 수업(익히기·만들기·퀴즈·말하기), 오늘의 한 문장 |
| 문장 암기 | 탭해서 뒤집는 플래시카드(한국어 ↔ 영어/중국어+병음), 외웠어요/아직 몰라요, 단원별 진행 |
| 말하기 | 문장 듣기(보통/천천히), 마이크로 따라 말하기, 유사도 점수와 친절한 피드백, '직접 말해봤어요' 대체 버튼 |
| 진도 | 스트릭·XP·외운 문장·완료한 날, 이번 주 기록, 14일 코스 목록, 언어별 요약, 설정(소리·속도·초기화) |

### 학습 콘텐츠

- 영어 14단원 · 중국어 14단원, 단원마다 실제로 쓰는 짧은 문장 5개 (총 140문장)
- 주제: 인사, 자기소개, 카페, 식당, 길 묻기, 쇼핑, 하루 일과, 날씨, 취미, 전화·약속, 감정, 가족·친구, 여행, 숫자·시간
- 중국어는 **간체자 · 병음 · 한국어 뜻 · 발음 팁 · 단어 블록**을 모두 제공
- 영어도 문장마다 연결 발음 팁 제공

### 학습 방식

1. **문장 익히기** — 원어민 음성(Web Speech)으로 듣고 뜻·병음·발음 팁 확인
2. **문장 만들기** — 흩어진 단어 블록을 눌러 문장 순서 완성 (Duolingo 스타일)
3. **듣기 퀴즈** — 문장을 듣고 4개 뜻 중 고르기, 즉시 정답 표시
4. **말하기** — 듣고 따라 말하면 `SpeechRecognition`으로 유사도 피드백. iOS 홈 화면 앱처럼 인식이 막히는 환경에서는 **'직접 말해봤어요 ✓'** 로 이어서 학습

### 기록

`localStorage`에 언어 선택, XP, 일별 XP, 스트릭(연속 일수·최고 기록), 수업 완료, 외운 문장, 설정을 저장합니다.

## PWA

- `manifest.json`: standalone, 테마 `#58cc02`, 192/512/마스커블 아이콘, 바로가기
- `sw.js`: 앱 껍데기 프리캐시 + 오프라인 내비게이션 폴백
- iPhone: Safari → 공유 → **홈 화면에 추가** → 전체 화면 앱처럼 실행
- 모든 경로가 `./` 상대 경로여서 GitHub Pages의 `/<저장소>/` 하위 경로에서도 동작

## 개발

```bash
# 정적 서버 (아무 서버나 가능)
python3 -m http.server 8765

# 자체 점검: 문법 + 콘텐츠 + 화면/수업 흐름 (quickjs)
python3 tools/run_selftest.py

# 아이콘 다시 만들기 (Pillow)
python3 tools/make_icons.py
```

앱은 `file://`로 열어도 동작하지만, 서비스 워커와 마이크 인식은 `https://` 또는 `localhost`에서만 동작합니다.
